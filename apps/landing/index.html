Built for speed, privacy, and independence

No corporate subscription. No black box servers. An assistant that lives in your home or on your laptop.

Sub-1.5s p50 Latency

Bypasses HTTP REST latency with an ultra-light typed WebSocket frame protocol. Deltas stream into your UI before traditional cloud chats even finish authentication.

Free-Tier Model Cascades

Routes intelligently through free API tiers: Groq, Cerebras, NVIDIA NIM. When rate limits (429) hit, Agni fails over in milliseconds to LM Studio or secondary providers.

Autonomous Background Jobs

Detached Bun daemon runs 24/7. It delivers your 07:55 AM briefing, monitors inboxes, performs repo tasks, and dispatches push notifications via ntfy.

Private Tailscale Mesh

End-to-end encrypted WireGuard networking. Connect your MacBook, iPhone, or Linux terminal directly to your home base from anywhere in the world without exposing public ports.

Native Apple-First Experience

Swift & Tauri client built strictly around macOS human interface guidelines. Minimal battery footprint, global ⌘K shortcut, transparent title bars, and full VoiceOver support.

100% Data Sovereignty

Your chats, documents, and memory vectors stay inside local SQLite databases with strict mode-600 permissions. Never harvested for AI training, never leaked in third-party breaches.

Architecture Diagram

The Agni Ecosystem Flow

A simple, bulletproof topology designed to resist outages, subscription pricing, and latency.

LAYER 1

Clients

Native Mac App (Swift), Android / iOS (Tauri 2), and interactive CLI (tools/cli).

LAYER 2

Wire Protocol v1

Encrypted Tailscale socket sending typed binary & JSON frames (`turn`, `delta`, `notify`).

LAYER 3

Agni Server Daemon

Bun runtime + SQLite stores (tasks, threads, memory) + Autonomous Job scheduler.

LAYER 4

Model Cascade Router

Auto-routes Groq ➔ Cerebras ➔ NVIDIA ➔ Local LM Studio. 0 downtime on 429 rate limits.

Quickstart in 4 Steps

Clone, configure your free API keys, and run the daemon in under 60 seconds.

1

Install Dependencies

Ensure you have Bun installed, then clone the repository and install packages.

git clone https://github.com/ynr/Agni-Bot.git && cd Agni-Bot && bun install
2

Configure Free Provider Keys

Add at least one free API key (Groq, Cerebras, or NVIDIA NIM) into your local .env file.

cp .env.example .env && nano .env
3

Start the Detached Daemon

Run migrations and launch the background daemon. It writes a PID file and begins health checks.

bun run migrate && bun run daemon start
4

Pair Device & Chat

Pair your Mac or terminal client and launch the interactive chat REPL.

bun run pair --name Mac && bun run chat
